# Notification System Design

## Problem Statement
Design a notification system that supports Email, SMS, Push notifications
and allows adding new channels without modifying existing code.

## Design Patterns Used
- Strategy Pattern: for notification channels
- Factory Method: for strategy creation
- Template Method: for notification workflow

## Current Status
Work in progress – actively refactoring and improving design.

## Future Enhancements
- Decorators for retry, logging
- Configuration-based channel selection
- Dependency Injection
